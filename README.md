# Gozie AI (starter)

This is the first static UI prototype for Gozie AI.

## What works
- Responsive chat-style interface
- Sidebar conversation history saved locally in the browser
- New chat and clear history
- Dark/light theme
- Accent colour selector
- Mobile sidebar

## Not connected yet
- Google/email sign-in
- Real SmolLM3 responses
- Server-side storage and cross-device chat history

The current assistant responses are intentionally placeholders. Do not publish API keys or other secrets in this repository.

## Publish with GitHub Pages
1. Open the repository `gozie-ai2` on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html` and this `README.md` from this folder.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**.
7. Choose branch `main`, folder `/(root)`, then Save.
8. Wait for GitHub Pages to publish the site. The URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/gozie-ai2/`.

This interface is a prototype only. Configure authentication and a secure backend before inviting public users.
